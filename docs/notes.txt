to start fresh:


config.h / config.c: Dedicated entirely to reading .conf files, validating required directives like listen and root, and populating your configuration structs without mixing socket code into the parser.

server.h / server.c: Handles low-level POSIX network setup—creating the socket, setting SO_REUSEADDR, binding to the validated port, and managing the listen queue.

http.h / http.c: Focuses purely on parsing incoming client requests, extracting the Host header for virtual hosting, matching it against your loaded configurations, and streaming the correct index.html file back to the client.

main.c: Acts as the lightweight controller—handles the first-run installation checks, triggers directory creation, loads the site configurations, supports the -t test flag, and boots the main event loop.
